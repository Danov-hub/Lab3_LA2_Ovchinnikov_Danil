# Задание 1

## Задача 11

### Текст задачи
Первый массив, размерностью n х m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по столбцам от последних элементов столбца к первым.
Второй массив, размерностью n х n, заполняется случайными числами так, что в каждом столбце получается возрастающая последовательность элементов.
Третий массив, размерностью n х n, заполняется для произвольного n так же, как для n=5 (простыми числами по порядку).

### Алгоритм решения
Для реализации задачи создано три конструктора в классе `MatrixTask`. 
Первый конструктор принимает размерность и использует вложенные циклы (внешний по столбцам, внутренний снизу вверх). Для защиты от некорректного ввода используется `int.TryParse` внутри цикла `while`.
Второй конструктор генерирует для каждого столбца базовое случайное число, которое затем увеличивается на случайную величину для каждого следующего элемента строки.
Третий конструктор содержит предварительно созданный массив простых чисел, элементы которого последовательно записываются в матрицу.

# Задание 2

## Задача 11

### Текст задачи
В двумерном массиве записаны по m оценок n школьников. Укажите номера школьников, средняя оценка которых больше 4.5.

### Алгоритм решения
Создан статический метод `FindExcellentStudents`. В начале программы с помощью цикла выводятся оценки каждого школьника. Затем для каждого школьника вычисляется сумма его оценок и делится на их количество (находится средний балл). Если средний балл больше 4.5, на экран выводится номер школьника и его средний балл (округленный до двух знаков с помощью форматирования `F2`).

# Задание 4

## Задача 11

### Текст задачи
Бинарные файлы. Найти количество квадратов нечетных чисел среди компонент файла. Исходный файл необходимо заполнить случайными данными.

### Алгоритм решения
Заполнение файла организовано отдельным методом с использованием `BinaryWriter`. Затем файл открывается через `BinaryReader` и считывается до конца. Если число нечетное (`num % 2 != 0`), из него извлекается квадратный корень, приводится к целому числу `(int)Math.Sqrt(num)`. Если квадрат этого корня равен исходному числу, счетчик увеличивается.

# Задание 5

## Задача 11

### Текст задачи
Бинарные файлы и структуры. Файл содержит сведения об игрушках: название, стоимость и возрастные границы. Получить название самой дорогой игрушки для детей до четырех лет. Обязательно использовать xml сериализацию.

### Алгоритм решения
Создана структура `Toy` (без автосвойств, с приватными полями и свойствами). Массив игрушек сохраняется в XML-файл с помощью `XmlSerializer`. Затем файл десериализуется обратно в массив. В цикле перебираются все игрушки: если минимальный возраст (`MinAge`) меньше или равен 4, и стоимость больше текущей максимальной, игрушка запоминается. В конце выводится имя и цена найденной игрушки.

# Задание 6

## Задача 11

### Текст задачи
Текстовые файлы. В файле хранятся целые числа по одному в строке. Найти среднее арифметическое максимального и минимального элементов. Исходный файл заполнить случайными данными.

### Алгоритм решения

# Задание 7

## Задача 11

### Текст задачи
Текстовые файлы. В файле хранятся целые числа по несколько в строке. Вычислить произведение чётных элементов. Исходный файл заполнить случайными данными.

### Алгоритм решения
Файл заполняется случайными числами через `StreamWriter` (по несколько в строку). При чтении каждая строка разбивается на части с помощью `Split`. Каждая часть преобразуется в число. Если число четное и не равно нулю, оно умножается на общую переменную произведения. Предусмотрена проверка, если четных чисел нет, произведение равно нулю.

# Задание 8

## Задача 11

### Текст задачи
Текстовый файл. Переписать в другой файл строки, в которых нет латинских букв.

### Алгоритм решения
Создается исходный файл с тестовыми строками. Файл построчно считывается. Каждая строка проверяется посимвольно: если символ попадает в диапазоны `a-z` или `A-Z`, устанавливается флаг наличия латиницы. Если после проверки флаг остался ложным, строка записывается в результирующий массив. Затем отфильтрованные строки записываются в новый текстовый файл.
